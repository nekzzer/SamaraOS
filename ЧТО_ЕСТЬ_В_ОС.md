# Что есть в SamaraOS

SamaraOS — хобби-ОС для 32-битного x86 (i686), загружается по Multiboot, работает в QEMU.
Ядро написано на C (~26 тыс. строк своего кода + DOOM), пользовательские программы —
обычные статические Linux-бинарники (musl), которые ядро запускает через
совместимый с Linux i386 интерфейс системных вызовов.

---

## Быстрый старт

```
make            # собрать ядро  -> build/samara.elf
make run        # запустить в QEMU (KVM, 1 ГБ, gcc + исходники, диск, сеть, звук)
```

| Команда | Что делает |
|---|---|
| `make run` | обычный запуск; грузит **самое новое** ядро: хостовое или собранное самой ОС (с `disk.img`) |
| `make run SELF=0` | всегда хостовое ядро |
| `make run VIDEO=1920x1080` | разрешение экрана гостя (по умолчанию 1600×900, показывается 1:1) |
| `make run APPEND="..."` | доп. параметры ядра (см. «Параметры ядра») |
| `make run-doom` | с диском `Doom1.WAD` для DOOM |
| `make run-debug` | без KVM, с `-d int` (отладка прерываний) |
| `make iso` / `run-iso` | загрузочный ISO (GRUB) |
| `make gcc-tar` / `src-tar` | модули с gcc и исходниками ОС |

С хоста в работающую ОС:
```
ssh -p 2222 root@localhost          # пароля нет
telnet localhost 2323
scp -O -P 2222 файл root@localhost:/tmp/
```

## Ядро

**Загрузка и процессор**
- Multiboot 1 (QEMU `-kernel`, GRUB), GDT/TSS, IDT, PIC, PIT 1 кГц.
- Пейджинг: 4 МБ-страницы, тождественное отображение 4 ГБ для ядра.
- FPU x87 + **SSE/SSE2** (CR4.OSFXSR, сохранение через FXSAVE при переключении задач).
- Multiboot-модули (`-initrd a.tar,b.tar`): переносятся наверх RAM и распаковываются в ФС без копирования.

**Память**
- Куча ядра 64 МБ (для драйверов и DMA) + **большая арена в верхней памяти** под содержимое файлов.
- **Прямое отображение 1 ГБ физической памяти** (`0x40000000`): процессам доступно всё ОЗУ, а не 48 МБ, как было.
- Пул физических фреймов, копирование страниц при `fork`, стек растёт по требованию, `mmap`/`munmap`/`brk`.

**Процессы и задачи**
- Вытесняющая многозадачность (таймер), задачи ядра и процессы ring 3.
- ~190 системных вызовов Linux i386 (`int 0x80`): `fork`/`clone`/`vfork`, `execve` (с `#!`),
  `wait4`, `pipe`, `dup2`, `select`/`poll`, сокеты, сигналы с обработчиками, `sigaction`,
  `alarm`/`setitimer`, TLS (`set_thread_area`), `getrandom`, `readlink /proc/self/fd/N` и т.д.
- Загрузчик ELF: обычные `ET_EXEC` и **static-PIE** (так собраны binutils).
- До 48 процессов, **1024 дескриптора** на процесс.
- Сессии, группы процессов, **управляющий терминал** (`setsid`, `TIOCSCTTY`, `/dev/tty`).
- Фоновые процессы (`cmd &`, запуск с иконок): stdio в `/dev/null`, освобождаются сами.
- Отладка: `strace=PID` в параметрах ядра — журнал вызовов процесса в COM1 при его выходе.

**Терминалы**
- Консольный tty с дисциплиной линии termios (канонический ввод, эхо, `^C`→SIGINT, `^\`, `^D`).
- **Псевдотерминалы**: `/dev/ptmx`, `/dev/pts/N` — для sshd и telnetd (до 16 штук).
- Интерпретатор ANSI/VT100 (`TERM=linux`): области прокрутки, вставка/удаление строк и символов,
  **true color** (`38;2;r;g;b`), 256 цветов, жирный/тусклый/подчёркнутый/зачёркнутый,
  **альтернативный экран** (`?1049h`), скрытие курсора (`?25l`), **UTF-8**.
- SIGWINCH при изменении размера окна терминала.

## Файловые системы и устройства

| Путь | Что это |
|---|---|
| `/` | ramfs в памяти (всё, кроме `/mnt`, теряется при перезагрузке) |
| `/mnt` | **FAT32 с `disk.img`**, чтение и запись, длинные имена, сохраняется между запусками |
| `/proc` | `meminfo cpuinfo uptime stat loadavg mounts version filesystems`, `/proc/<pid>/…` |
| `/dev` | `null zero random urandom tty console fb0 input ptmx pts/N hda sda …` |
| `/opt/gcc` | gcc 11 + binutils + make (модуль `build/gcc.tar`) |
| `/usr/src/samaraos` | исходники ядра (модуль `build/src.tar`) |

FAT12/16 только на чтение — это диск с музыкой (`music/` на хосте). Команды `fatmount`, `fatls`, `fatload`.

**Драйверы**
- Клавиатура PS/2: раскладки EN/RU (CP866), **Alt+Shift** переключает, F1–F10, стрелки, Home/End/PgUp/PgDn.
- Мышь PS/2 **IntelliMouse с колесом**.
- Видео: VGA-текст 80×25, **VBE-кадровый буфер** (до 1920×1080×32), двойная буферизация, `/dev/fb0`, `/dev/input`.
- Диски: ATA PIO, **AHCI (SATA, DMA)**.
- Звук: **SoundBlaster 16** (PCM, WAV), PC-спикер.
- Сеть: **RTL8139**, PCI-перечисление.

## Сеть

- Свой стек: Ethernet, ARP, IPv4, ICMP (ping), **TCP** (клиент и сервер), **UDP**, loopback.
- Фиксированный адрес `10.0.2.15/24`, шлюз `10.0.2.2` — это и есть хост (QEMU user-net). DHCP нет;
  в ядре DNS нет, программы на musl резолвят имена сами через `/etc/resolv.conf`.
- Сокеты BSD для программ: `socket bind listen accept connect send recv shutdown getsockopt …`.
- **SSH**: сервер и клиент dropbear 2025.88 (`ssh`, `scp`, `dropbearkey`, `dbclient`).
- **telnet**: `telnetd` с `login` и клиент `telnet` (busybox); также `nc`, `wget`.
- При загрузке `/etc/rc` сам поднимает `dropbear` (:22) и `telnetd` (:23); ключ хоста хранится на `/mnt`.
- QEMU пробрасывает только на loopback хоста: `127.0.0.1:2222` → 22, `127.0.0.1:2323` → 23.
- Из ОС на хост: `ssh eralp@10.0.2.2` и т.п.

## Консоль и терминал

- **Графическая консоль** сразу после загрузки (вместо VGA-текста; `textmode` — вернуть VGA).
- Шрифт DejaVu Sans Mono, обычный и жирный, **4 размера**: 8×16, 10×20, 12×24, 16×32, ~1500 символов Unicode.
- **Ctrl +/−** — размер шрифта, **колесо мыши** — история прокрутки (1000 строк).
- Рамки `─│╭╮`, блоки `▀▄█░▒▓`, Брайль и стрелки powerline рисуются процедурно — ровно при любом размере.
- Градиентный баннер `SAMARA OS` и цветное градиентное приглашение.

## Встроенный шелл SamaraOS

**Tab-дополнение** (команды, пути; второй Tab — список), история (↑↓), `cmd &` — в фоне.
GUI-программа, запущенная из терминала, как только откроет своё окно, отпускает терминал.

| Группа | Команды |
|---|---|
| Файлы | `ls cd pwd cat mkdir touch rm cp mv head tail wc grep find df` |
| Система | `help clear echo uptime mem ps procs uname whoami about date history sleep shutdown reboot exit neofetch disks kbdignore strace` |
| Программы | `sh run python python3 nano edit calc` |
| Графика | `desktop wallpaper bounce paint clock browser www snake doom doom2 play player music` |
| Сеть | `ifconfig ping wget` |
| Звук | `beep playwav stopwav sbinfo playfat` |
| Диски и FAT | `disk fatmount fatls fatload` |
| Раскладка | `klayout` |

Всего 70 встроенных команд; всё остальное ищется в `PATH`
(`/bin /sbin /usr/bin /usr/sbin /usr/games /opt/gcc/bin`) и запускается как программа.

## Пользовательские программы

| Программа | Что это |
|---|---|
| **busybox** | 402 апплета: `sh` (ash), `ls vi less top find awk sed grep tar wget nc telnet telnetd login …` |
| **nano 7.2** | полноценный редактор (ncurses), колесо мыши скроллит текст |
| **micropython** | Python 3 + модуль `samara` (окна на рабочем столе) |
| **tcc 0.9.27** | маленький компилятор C + musl (`/usr/include`, `/usr/lib`) |
| **gcc 11.2 + binutils 2.37 + GNU make** | в `/opt/gcc`, по умолчанию `-static -no-pie` |
| **dropbear** | `ssh`, `scp`, `dropbear`, `dropbearkey` |
| **samarafetch** | логотип и сведения о системе в градиентах; `--ps1` — приглашение для `sh` |
| **tetris**, **breakout.py** | игры в `/usr/games` (иконки на рабочем столе) |

`/usr/include/samara.h` — API окон для своих программ на C (`sm_open`, `sm_rect`, `sm_text`,
`sm_event`, `sm_present` …), пример — `/usr/src/samara/hello.c`, `hello.py`.

Шелл `sh` при входе по ssh/telnet показывает `samarafetch`, приглашение с градиентом,
`ls --color`, `COLORTERM=truecolor`; программы получают и выводят UTF-8.

## Рабочий стол (`desktop`)

**Оконный менеджер**
- Композитор с «повреждёнными» областями, отсечением невидимого и двойной буферизацией, **60 FPS**.
- Окна: перетаскивание, **ресайз за края и углы** (курсоры-стрелки), **развернуть** (кнопка □,
  двойной клик по заголовку, бросок к верхнему краю), свернуть, **F11 — фуллскрин**.
- Панель задач: меню «samara», кнопки окон, индикатор сети, переключатель EN/RU, часы.
- Иконки на рабочем столе (игры из `/usr/games` появляются автоматически), обои BMP (`wallpaper`).
- Колесо мыши уходит окну под курсором; курсор мыши без мерцания.

**Меню «samara»**: Terminal, Web Browser, Music Player, Paint, Clock, About, Welcome, System Info,
Reboot, Shutdown, Exit Desktop.

**Приложения**
- **Terminal** — встроенный шелл в окне (всё из раздела «Консоль»).
- **Web Browser** — HTTP (без HTTPS), IP-адреса, простой HTML, колесо, перенос текста при ресайзе.
- **Music Player** — мелодии через PC-спикер, WAV через SB16.
- **Paint** — рисование, сохранение в BMP на `/mnt`.
- **Clock** — аналоговые и цифровые часы.
- **Snake**, **Bounce**, **DOOM** (doomgeneric, нужен WAD) — игры; DOOM масштабируется в 2–3 раза.
- **Окна программ** (`samara.h`, micropython): масштаб целым числом с полями, текст рисуется
  чётко в разрешении экрана, событие колеса, игры не занимают терминал.

## Самосборка

ОС может собрать сама себя:

```
selfbuild                              # внутри SamaraOS (~20 с с KVM)
```

Собирает ядро gcc 11 из `/usr/src/samaraos` и кладёт `/mnt/samara.elf`; следующий
`make run` на хосте загрузит его, если оно новее хостовой сборки. Результат совпадает с
хостовой сборкой тем же gcc бит в бит.

## Параметры ядра

Передаются через `make run APPEND="..."` или `-append`.

| Параметр | Что делает |
|---|---|
| `video=WxH` | разрешение экрана |
| `textmode` | консоль в старом VGA-тексте вместо графики |
| `noservices` | не запускать sshd/telnetd |
| `autosh=<скрипт>` | выполнить `sh -c <скрипт>` с выводом в COM1 и выключиться (тесты) |
| `wmstats` | FPS и время кадра рабочего стола в COM1 раз в 2 с |
| `strace` / `strace=PID` | трассировка системных вызовов |
| `kbd_ignore=35,2b` | игнорировать скан-коды сломанных клавиш |

## Ограничения

- Только одно ядро процессора, нет потоков в одном адресном пространстве (`CLONE_VM` = fork).
- Нет HTTPS в браузере и DHCP; сеть рассчитана на QEMU user-net.
- Всё, что не на `/mnt`, живёт в памяти и пропадает при перезагрузке.
- root без пароля (ssh/telnet доступны только с loopback хоста).
- Широкие символы (CJK, эмодзи) не рисуются — вместо них `�`.
- `scp` с хоста требует флаг `-O` (нет SFTP-сервера).
